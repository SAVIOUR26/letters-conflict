# Origins cover (draft 1)

Original artwork generated by `build_cover.js` (seeded, reproducible) from the cover brief in the blueprint (§7):
*fragments before understanding* — the letters A F R I C A carved across a coursed dry-stone wall, broken at the
joints, the last letter sinking into laterite earth; loose fragments (S, E) lying in the soil.

```bash
node cover/build_cover.js 270 cream dusk   # page count, paper (cream|white) → spine width, palette
```

**Palettes** (stone and red earth stay; sky and type change): `dusk` (deep indigo sky with a warm glow behind the wall — current favourite), `laterite` (terracotta), `ochre` (saffron dawn), `charcoal` (near-black with gold), `cream` (the first draft, matching *The Japanese Way*). Side-by-side: `output/origins_cover_palette_options.jpg`.

Outputs in `cover/output/` (prefixed with the palette, e.g. `origins_dusk_…`):
- `origins_<palette>_cover_wrap.pdf` — full KDP paperback wrap with 0.125 in bleed (12.925 × 9.25 in at 270 cream pages)
- `origins_<palette>_cover_preview.jpg` — the wrap with trim and spine guides (blue dashes), for review only
- `origins_<palette>_front_ebook.jpg` — Kindle front cover, 1600 × 2400 px
- `origins_<palette>_front_trim.png` (not committed; regenerate) — front panel at 300 dpi, trimmed
