# Origins cover (draft 1)

Original artwork generated by `build_cover.js` (seeded, reproducible) from the cover brief in the blueprint (§7):
*fragments before understanding* — the letters A F R I C A carved across a coursed dry-stone wall, broken at the
joints, the last letter sinking into laterite earth; loose fragments (S, E) lying in the soil.

```bash
node cover/build_cover.js 270 cream    # page count, paper (cream|white) → spine width
```

Outputs in `cover/output/`:
- `origins_cover_wrap.pdf` — full KDP paperback wrap with 0.125 in bleed (12.925 × 9.25 in at 270 cream pages)
- `origins_cover_preview.jpg` — the wrap with trim and spine guides (blue dashes), for review only
- `origins_front_ebook.jpg` — Kindle front cover, 1600 × 2400 px
- `origins_front_trim.png` — front panel at 300 dpi, trimmed
